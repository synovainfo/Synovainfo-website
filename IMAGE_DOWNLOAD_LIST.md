## Technical Verification & Quality Standards

1. **Format Routing**: All vector diagrams are implemented as high-precision scalable `.svg` files; photographic media are served as `.webp`/`.avif`.
2. **Next.js `<Image>` Protocol**: Mandatory `priority` setting on above-the-fold assets (1-20), `loading="lazy"` on all scroll assets.
3. **Themes**: Every vector asset features dark & light background adaptivity using CSS custom properties (`var(--color-...)`).
4. **Fallback Poster Frames**: Every HTML5 `<video>` element includes explicit `.jpg`/`.webp` poster images and `prefers-reduced-motion` compliance.
