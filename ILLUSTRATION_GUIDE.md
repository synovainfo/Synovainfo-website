# Synova Infotech — Illustration & Vector Graphic Style Guide

## 1. Visual Philosophy
- **Clean Technical Precision**: Diagrams use sharp vector paths (1.5px - 2.5px stroke weights) with neon cyan, blue, emerald, and purple glow accents on dark glass backgrounds.
- **No Generic Flat Cartoons**: Use architectural blueprints, node topology diagrams, vector data visualizations, and isometric technical schematics.

## 2. Color Language for Vectors
- **Cyan (`#06B6D4`)**: Microservices, Edge Network, API Endpoints.
- **Blue (`#2563EB`)**: Multi-Cloud Infrastructure, Storage, Databases.
- **Emerald (`#10B981`)**: Security, Health Checks, Verified SLA, Compliance.
- **Purple (`#8B5CF6`)**: AI Inference Engines, Vector DBs, Neural Pipelines.

## 3. Layering & Glass Backdrop
Every vector asset renders over a frosted dark glass panel (`rgba(15, 27, 45, 0.75)` with `1px solid rgba(255, 255, 255, 0.12)` border) with subtle ambient light gradients behind key nodes.
